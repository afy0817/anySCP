# i18n 전환 작업 지침 (에이전트용)

목표: 화면에 보이는 영어 문자열을 i18next `t()` 호출로 바꾸고, 영어(en)·한국어(ko) 번역 파일을 채운다.
설정 > 모양 > 인터페이스 > 언어 에서 English / 한국어 를 실시간으로 바꿀 수 있어야 한다.

## 이미 깔려 있는 것 (수정 금지)
- `src/i18n/index.ts` — i18next 초기화, `import i18n from "<상대경로>/i18n"`
- `src/i18n/i18next.d.ts` — en/*.json 기준으로 t() 키 타입 검사 (틀린 키는 tsc 에러)
- `src/i18n/locales/{en,ko}/common.json` — 공용 동작 단어(actions.cancel 등). 읽기 전용. 영어 원문이 정확히 같을 때만 재사용,
  아니면 자기 네임스페이스에 키를 만든다.
- `vitest.setup.ts` 가 테스트 언어를 en 으로 고정

## 원칙
1. **en 값 = 원본 영어 문자열과 글자 하나까지 동일** (대소문자, 마침표, `…` vs `...`, 공백, 따옴표 모양 전부).
   원본 테스트를 고치지 않고 그대로 통과해야 한다. 테스트가 깨지면 테스트가 아니라 en 값을 고친다.
   테스트 파일(`*.test.*`, `__tests__`, `tests/`)은 수정 금지.
2. **ko 값은 이미 만든 번역을 재사용**: 브랜치 `ko-direct` 에 같은 파일의 한국어 직접 번역본이 있다.
   `git diff v0.11.1 ko-direct -- <파일경로>` 로 영어→한국어 대응을 보고 옮긴다. 용어·문체는 `.ko/GLOSSARY.md`.
   용어 통일: Credentials = 자격 증명, Label(표시명) = 표시 이름, (copy) = (사본), pane = 창.
3. 번역하지 않는 것은 GLOSSARY "그대로 두는 것" 과 같다(로직 값, id, data-testid, className, console, 예시값, 고유명사, 글꼴 이름…).

## 사용법
- 컴포넌트: `const { t } = useTranslation("dashboard");` → `t("hostEdit.title")`
  다른 네임스페이스도 쓰면 `useTranslation(["dashboard", "common"])` → `t("common:actions.cancel")`
- React 밖(store, util): `import i18n from "../i18n";` → `i18n.t("core:hosts.loadFailed")`
  **메시지를 만드는 그 시점에 호출** (모듈 최상위에서 호출 금지 — 언어가 실행 중에 바뀜)
- 모듈 최상위 상수의 라벨(SECTIONS, 옵션 목록, 상태 라벨 맵 등): 문자열 대신 **키**를 두고 렌더 시점에 `t()`.
  예) `const SECTIONS = [{ id: "appearance", labelKey: "sections.appearance" }] as const;` → `t(s.labelKey)`
  또는 컴포넌트 안에서 `useMemo(() => [...], [t])` 로 생성.
- 화면 표시 + 로직에 같이 쓰이는 값(상태, 환경, 인증 방식…): 값은 그대로, `Record<값, 키>` 로 표시만 번역.
- 보간: `t("deleteConfirm", { name })` ↔ en `"Delete \"{{name}}\"?"`, ko `"\"{{name}}\"을(를) 삭제할까요?"`
- 복수형: `t("itemsSelected", { count: n })` ↔ en `itemsSelected_one: "{{count}} item selected"`, `itemsSelected_other: "{{count}} items selected"`,
  ko `itemsSelected_other: "{{count}}개 선택됨"` (ko 는 _other 하나만). 원본이 n===1 분기를 쓰던 곳만 복수형 사용.
- 태그가 섞인 문장: `<Trans t={t} i18nKey="x" components={{ code: <code className="…" /> }} />`, en `"Type <code>DELETE</code> to confirm"`.
  단순하면 문장을 쪼개도 된다(단, 원본 테스트가 보는 텍스트가 그대로 나와야 함).
- 키 이름: camelCase 중첩, 컴포넌트/기능 단위로 묶기. 예) `hostEdit.fields.hostname.label`, `toasts.deleteFailed`.

## 실시간 전환 주의
- 번역된 문자열을 zustand 상태나 모듈 변수에 저장하지 말 것(전환해도 안 바뀜). 사용자가 만든 데이터(복제 시 "(사본)" 접미사 등)는 예외.
- 페이지 탭 이름은 저장된 label 이 아니라 page id 로 렌더 시점에 번역(UnifiedTabBar 담당 에이전트).

    cd /Users/pedro/Documents/workspace/anySCP
    pnpm exec tsc --noEmit          # 틀린 키·타입 오류 (다른 에이전트 파일의 일시적 오류는 보고만)

빌드(`pnpm build`, `tauri build`)와 git commit 은 하지 않는다. 담당 외 파일은 건드리지 않는다.
